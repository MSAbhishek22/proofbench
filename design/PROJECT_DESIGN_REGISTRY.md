**ProofBench (this project)** differs on every axis:
- Concept: calibration-bench measuring instrument; the spec is a specimen.
- Palette: graphite chassis + phosphor green/amber/fault-red measurement
  semantics on dark plates (not candlelit, not paper, not stall-warm).
- Typography: monospace-led silkscreen system (no serif, no display face).
- Layout: numbered instrument modules in run order, single column, graticule
  only behind the measurement module (not a dashboard grid, not a form, not
  a phone column).
- Signature interaction: the result trace — an oscilloscope SVG line whose
  shape encodes the pass/fail sequence of the run; verdict as a recessed
  DVM-style readout (`SPEC HOLDS` / `SPEC DISPUTED`).
