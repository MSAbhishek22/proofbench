# LedgerLite — product spec v0.3

LedgerLite supports CSV export of all reports.
LedgerLite supports PDF export of all reports.
GET /health returns status 200.
GET /receipt returns a body containing receipt_id.
The maximum upload size is 10 MB.
Data retention is 30 days.
The API responds within 200 ms for health checks.
All endpoints require authentication.
LedgerLite never stores passwords in plain text.
LedgerLite does not support webhooks.
LedgerLite is the friendliest accounting tool ever made.
